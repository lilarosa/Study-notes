# Todo List 练习项目

这是一个适合初学者练习 HTML、CSS 和 JavaScript 的小项目。

## 你将练习的内容

- 使用 HTML 结构化页面
- 使用 CSS 美化界面
- 使用 JavaScript 处理事件
- 使用 localStorage 保存数据
- 练习增删改查和状态管理

## 推荐练习顺序

1. 先完成 `script.js` 里的 `loadTodos()`
2. 再完成 `saveTodos()`
3. 然后完成 `addTodo()`
4. 接着完成 `toggleTodo()` 和 `deleteTodo()`
5. 最后完成 `renderTodos()` 和 `setFilter()`

## 你可以自己补充的点

- 支持编辑任务内容
- 支持按优先级排序
- 支持清空已完成任务
- 加入任务创建时间
- 加入统计数量

## 运行方式

直接用浏览器打开 `index.html` 即可。
