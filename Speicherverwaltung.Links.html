20 Prozesse mit höchstem Speicher-Verbrauch

Get-Process | sort WS -Descending | select –First 20

20 Prozesse mit höchstem Verbrauch an nicht auf einen Datenträger auslagerbarem Speicher (non paged memory)

Get-Process | sort NPM -Descending | select –First 20

20 Prozesse mit höchstem Verbrauch an auf einem Datenträger auslagerbaren Speicher (paged memory)

Get-Process | sort PM -Descending | select –First 20

Welche 10 Prozesse laufen am längsten?

Get-Process | sort ID | select –First 10

Wieviel Prozesse laufen jetzt?

(Get-Process).Count

Virtual Memory Size aller Prozesse abfragen

Write-Output("Gesamte Virtual Memory Belegung aller Prozesse: {0:N3} TiB" -f ((Get-Process|Measure-Object -Property VirtualMemorySize64 -Sum).Sum/1TB))
